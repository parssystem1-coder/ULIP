# Source Access and Compliance Principles

## 1. Authorized access only

The system operates only on data the deployment is permitted to access.

## 2. Do not bypass controls

Explicitly out of scope:

- CAPTCHA solving/bypass
- rate-limit evasion
- session/cookie theft
- credential abuse
- anti-bot evasion
- unauthorized private-data extraction

## 3. Data minimization

Store only what is required for product functionality, evaluation and audit.

## 4. Provenance

Every source-derived record should retain source type, source reference and collection time where possible.

## 5. Retention

Raw data should have a defined retention policy and should not be retained indefinitely merely because storage is available.

## 6. Future review

Each new connector should go through a connector-specific review covering access method, permissions, terms/policies applicable to the deployment, data categories collected and retention requirements.
